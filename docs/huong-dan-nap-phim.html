Nạp Video, SRT & Voiceover

Đưa phim 150.1 爹娘双尊我躺赢 vào YT Review Studio theo workflow Sub Translate / Render — từng bước theo đúng giao diện.

Trước khi bắt đầu: ep01 anh/chị vừa tạo là Story Channel (dành cho AI audio story) nên không nhận video/SRT — vì vậy mới thấy lỗi "story-factory-disabled". Cứ để đó hoặc xóa ở tab Projects (dòng Series · ep01 → Delete). Việc nạp phim cần một Review Project, tạo ở Bước 1.

1Tạo Review Project với workflow "Sub Translate / Render"

Vào tab Projects → bấm New Review Project → điền form. Quan trọng nhất là ô Workflow type — phải chọn Sub Translate / Render thì mới có các bước Media / Subtitles.

4Nạp folder audio thuyết minh — mục Voiceover

Ngay dưới phần Import SRT trong stage Subtitles có mục Voiceover. Folder 2112 file wav không upload qua browser — chỉ cần dán đường dẫn, server đọc thẳng từ ổ đĩa:

#/project/su-150-1/content · Subtitles
Voiceover
D:\DOCS\SUPHAM\New folder\su 150.1-20260824T025728Z-1-001\su 150.1\audio_usa\audio_usa
— để trống: tự dùng source SRT vừa upload —
Import Voiceover Segments Render Voiceover Track

Status sẽ báo Imported 2112/2112 segments — file 0001.wav khớp cue 1, 0002.wav khớp cue 2… Nếu báo missing/unmatched, kiểm tra số lượng cue trong SRT có khớp số file không.

Import xong bấm Render Voiceover Track — job chạy nền, ghép 2112 đoạn thành một track audio theo đúng timeline SRT. Theo dõi tiến độ ở status góc phải trên.

5Các bước còn lại

Translation (nếu cần dịch phụ đề) → Publish › Source Risk (xác nhận trách nhiệm nguồn — bắt buộc trước khi render) → Edit › Render → Publish › Export.
  • Mọi thao tác chậm (render, import lớn) đều chạy nền — đừng đóng tab, status góc phải hiện phần trăm.
  • Muốn sửa/xóa project: tab Projects có nút Edit / Delete ngay trên từng dòng.
Tóm tắt: Tạo project workflow Sub Translate / Render → Media: chọn file mp4 → Subtitles: chọn file SRT → Voiceover: dán đường dẫn folder audio → Import → Render Voiceover Track.
