# Agent Instructions

Build this project as a local-first AI studio for original YouTube review and
analysis content.

Do not implement features whose purpose is to bypass copyright detection,
mass-reupload third-party footage, remove watermarks, evade Content ID, or
automatically harvest copyrighted anime/donghua/movie clips for reuse.

Prefer a small, usable MVP over a broad automation suite. Keep human approval
points for script, source footage, copyright-risk checklist, and final render.

Use TypeScript/Node for the initial app unless an approved plan changes the
stack. Use FFmpeg for rendering. Keep generated project outputs under an ignored
workspace folder.
